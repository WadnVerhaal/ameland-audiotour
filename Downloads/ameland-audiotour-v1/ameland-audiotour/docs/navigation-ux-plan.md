# Navigatie UX

De kaart gebruikt drie expliciete camerastanden:

- Routeoverzicht: toont gebruiker, route en gekozen stop.
- Volg mij: houdt de kaart op de actuele GPS-locatie.
- Vrij verkennen: ontstaat alleen na handmatig slepen of zoomen en toont een duidelijke knop om de navigatie te hervatten.

De routegeometrie blijft in alle standen zichtbaar en wordt via de interne walking-routing API ververst zonder de bestaande route tijdens laden te verwijderen.
